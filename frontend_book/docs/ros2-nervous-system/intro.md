# Introduction to The Robotic Nervous System (ROS 2)

Welcome to the module on the Robotic Nervous System (ROS 2). This module is designed for AI engineers, software developers, and robotics students entering Physical AI and humanoid robotics with prior Python and AI fundamentals.

## Overview

This module explores how ROS 2 functions as the distributed nervous system of humanoid robots, enabling communication between AI software and physical hardware. You'll learn about:

- How ROS 2 enables embodied intelligence in humanoid robots
- Communication patterns using nodes, topics, and services
- How to bridge Python AI agents to robot bodies

## Structure

The module is organized into three chapters:

1. **ROS 2 and Embodied Intelligence**: Understanding ROS 2 as a distributed robotic nervous system
2. **Communication in Humanoid Robots**: Learning about nodes, topics, services, and actions
3. **Bridging Python AI Agents to Robot Bodies**: Connecting AI algorithms to robot control

## Learning Objectives

After completing this module, you will be able to:
- Explain why ROS 2 is essential for physical robots
- Design basic ROS 2 communication graphs
- Choose between topics, services, and actions appropriately
- Understand the role of rclpy in connecting AI agents to ROS 2
